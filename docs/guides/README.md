# Guides

Step-by-step instructions.

- [Check a training segment](check_a_segment.md): check the released model, from a laptop (no
  GPU) to a one-click RTX 5090 check.
- [The `ovllm verify` artifact verifier](ovllm_verify.md): verify a published model directory,
  publish one, and run the reproducibility matrix.
- [Run the model in Ollama](ollama.md): export the chat model to GGUF and run it in Ollama or
  llama.cpp.
